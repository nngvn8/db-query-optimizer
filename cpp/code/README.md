# C++ Optimizer Development Environment

This directory contains a separate development and testing environment for the C++ optimizer components. The tools here are intended for developers working on the core optimizer logic.

## Makefile

The `Makefile` in this directory is used for building and running a test executable called `runner`. It is configured to compile the sources from the `src` and `examples` directories.

### Main Targets

*   `make all`: Compiles the `runner` executable.
*   `make run`: Runs the `runner` executable.
*   `make clean`: Removes the compiled executable and object files.
*   `make run_fresh`: Cleans the previous build, then builds and runs the executable.

This `Makefile` is useful for quick, iterative development and testing of the optimizer logic without going through the main CMake build process.

## executor.sh

The `executor.sh` script is a utility for running the optimizer and visualizing the generated query plans.

It performs the following steps:
1.  Runs `make run_fresh` to build and execute the `runner`.
2.  Uses the `dot` utility (from Graphviz) to convert the `.dot` files (generated by the `runner`) into PNG images. These images represent different stages of the query plan optimization.

To use this script, you need to have `graphviz` installed (`sudo apt-get install graphviz` on Debian/Ubuntu).

## `src/util/generate_sbb_sql_queries.py`

This Python script is a helper for generating the Star Schema Benchmark (SSB) queries as individual `.sql` files. It contains a dictionary of query strings and writes each of them to a file (e.g., `q1-1.sql`).

You can run it from the `cpp/code/src/util` directory:
```bash
python generate_sbb_sql_queries.py
```
This will populate the directory with the `.sql` files used for testing.
